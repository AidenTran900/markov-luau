# Installation

You can install MarkovLuau in two ways.

## Option 1: Wally

Wally is a package manager for Roblox. We recommend this option. Add this text to your `wally.toml` file:

```toml
[dependencies]
MarkovLuau = "aidentran900/MarkovLuau@0.1.0"
```

Then, run the `wally install` command in your terminal.

## Option 2: Manual Download

You can also download the `.rbxm` file directly. 

1. Go to the [Releases](https://github.com/AidenTran900/markov-luau/releases) page on GitHub.
2. Download the latest `.rbxm` file.
3. Open Roblox Studio.
4. Drag the `.rbxm` file into your Roblox project. Move the file to `ReplicatedStorage` or `ServerScriptService`.
